AlgoNest Privacy Policy

Effective date: September 14, 2026

AlgoNest saves accepted LeetCode submissions to a GitHub repository selected by the user.

Information handled

  • LeetCode submission source code, problem title, URL, slug, selected language, and submission status.
  • GitHub authentication information, including an OAuth access token.
  • The selected GitHub repository, repository owner, branch, and extension preferences.

How information is used

AlgoNest uses this information only to save accepted submissions and their README files to the GitHub repository selected by the user.

How information is stored and shared

GitHub authentication information and extension settings are stored locally in the browser's extension storage. Submission code and related problem metadata are sent over HTTPS directly to GitHub's API to create files in the repository selected by the user.

AlgoNest does not sell user data, use it for advertising, use analytics or tracking services, or send it to a developer-operated server.

Third parties

GitHub receives the information required to authenticate the user and save files to the selected repository. GitHub's handling of that information is governed by GitHub's own policies.

Data retention and deletion

Users can remove locally stored extension data by clearing the extension's data or uninstalling AlgoNest. Files already saved to GitHub remain in the user's selected repository and can be deleted there.
